# 🎂 Amna's Birthday Surprise

A personalised, interactive birthday surprise website built using **HTML, CSS, and Vanilla JavaScript**.

This project is designed as a small digital birthday experience, taking the visitor through multiple animated scenes, interactive surprises, personalised messages, and a birthday finale.

## ✨ Features

- **Seven Interactive Scenes** – A complete birthday experience with different scenes and transitions.
- **Animated Birthday Cake** – A celebratory cake animation with a birthday wish.
- **Pop the Balloons 🎈** – Click or tap balloons to pop them, trigger particle effects, and reveal personalised messages.
- **Floating Hearts** – Animated hearts and decorative visual effects.
- **Interactive Envelope** – An animated envelope that opens to reveal a personal letter.
- **Personalised Birthday Letter** – A special message with a typewriter-style reveal.
- **Kitten Celebration** – A cute animated celebration scene.
- **Background Music 🎵** – Optional instrumental background music with play/pause controls.
- **Responsive Design** – Layout adjustments for desktop, tablets, and mobile devices, including iPhones.
- **Replay Experience** – Option to watch the birthday surprise again.

## 🛠️ Technologies Used

**Note:** The music file is optional. If included, it must be named exactly `blue-instrumental.mp3` and placed in the same folder as the HTML file.

## 🚀 Getting Started

You don't need to install any frameworks, dependencies, or packages to run this project.

1. Clone or download this repository.
2. Make sure the HTML file and optional music file are in the same folder.
3. Open `index.html` in your browser.
4. Click or tap through the different birthday scenes.
5. Use the music button to start or pause the background music.

You can also use **VS Code Live Server** to run the project locally.

## 🎨 Customisation

The birthday experience includes personalised content such as:

- Birthday person's name
- Age
- Sender's name
- Personal birthday letter
- Individual messages revealed by popping balloons

These values can be customised in the JavaScript configuration section of the HTML file.

## 🎈 How to Interact

1. Start the experience from the welcome screen.
2. Enjoy the animated birthday cake.
3. Pop the balloons to reveal the hidden messages.
4. Continue to the interactive envelope.
5. Open the birthday letter.
6. Enjoy the kitten celebration.
7. Reach the final birthday surprise.

## 🌐 Deployment

This project can be hosted using **GitHub Pages**.

1. Upload the project files to a GitHub repository.
2. Rename the main HTML file to `index.html`.
3. Keep `blue-instrumental.mp3` in the repository's root folder if you want background music.
4. Open your repository's **Settings → Pages**.
5. Select the `main` branch and `/root` folder.
6. Save your settings.

GitHub Pages will provide a public link to your birthday website.
